# Sistema de Tarefas em Python

Aplicação desenvolvida em Python com o objetivo de praticar lógica de programação e aplicar, na prática, os conhecimentos adquiridos durante meus estudos.

## Sobre o projeto

O Sistema de Tarefas é uma aplicação simples executada pelo terminal, que permite cadastrar, visualizar, editar e excluir tarefas através de um menu interativo.

Este projeto também faz parte do meu processo de aprendizagem em Python. A ideia é continuar aprimorando a aplicação conforme novos conhecimentos forem adquiridos, adicionando funcionalidades e buscando melhorar a estrutura do código.

## Funcionalidades

- 📋 Visualizar tarefas cadastradas
- ➕ Adicionar novas tarefas
- ✏️ Editar tarefas existentes
- 🗑️ Excluir tarefas
- 🚪 Encerrar o sistema

## Tecnologias utilizadas

- Python

## Conceitos praticados

Durante o desenvolvimento foram utilizados conceitos como:

- Listas
- Estruturas condicionais
- Estruturas de repetição
- Funções
- "input()" e "print()"
- "enumerate()"
- Manipulação de listas
- Validação de entradas

## Evolução do projeto

Este projeto continuará sendo desenvolvido conforme avanço nos meus estudos.

Entre as melhorias planejadas para versões futuras estão:

- Tratamento de exceções

## 🎯 Objetivo

Mais do que desenvolver uma aplicação funcional, este projeto tem como objetivo registrar minha evolução na programação e colocar em prática novos conhecimentos ao longo do processo.
